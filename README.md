# 📊 Adidas Interactive Sales Dashboard (2023 - 2025)

An interactive analytics dashboard visualizing **Adidas** sales performance, operational trends, and customer demographics across key Middle Eastern markets (**Egypt, Iraq, KSA, Oman, and Lebanon**).

## 📌 Dashboard Highlights & Core Analysis

* **Sales Share by Country:** Visualizes the market distribution percentage where **Egypt** leads with **30%**, followed by **Iraq** (**28%**), **Oman** (**24%**), **KSA** (**12%**), and **Lebanon** (**6%**).
* **Gender Breakdown:** Features dynamic filtering capabilities to analyze purchasing preferences by customer gender (**Male / Female**).
* **Order Volume Per Country:** Tracks total transactions per market, led by **Iraq** (**371 orders**) and **Egypt** (**336 orders**), followed by **Oman** (**289 orders**), **KSA** (**123 orders**), and **Lebanon** (**81 orders**).
* **Order Trends Over Time (2023–2025):** A quarterly timeline chart mapping performance fluctuations from Q3 2023 through Q3 2025, reaching peak volumes of 122 orders per quarter.
* **Geographic Sales Map:** A spatial heat map showing geographic sales density across Egypt, Saudi Arabia, Oman, and Iraq.

## 🛠️ Data Challenges & Technical Solutions

* **Map Visual Issue Resolved:** During development, an issue occurred where geographical data failed to map correctly. This was successfully resolved by migrating, re-formatting, and restructuring the source data into a fresh worksheet to ensure smooth spatial rendering.

## 🎛️ Interactive Slicers

The dashboard allows real-time data filtering across multiple dimensions:
* **Demographics:** Region & Gender
* **Product:** Category (Accessories, Apparel)
* **Fulfillment:** Store Type (Online, Outlet, Retail, Wholesale)
* **Financials:** Payment Method (Apple Pay, Cash, Credit Card, Debit Card, Google Pay)
* **Timeline:** Customizable Order Date range (2023 – 2025)
